Mac Plaza's first private friend-testing release.

- Installer for Apple silicon Macs running macOS 15 or later.
- Discord setup opens on first launch with the test service preconfigured.
- Choose a Mii and opt into sharing it with your Discord friends without Plaza invitation codes.
- Signed private app updates, automatic update checks, and optional automatic installation.
- Discord custom status notes, game gatherings, friend search, and local custom Mii priority.

This preview is not Apple notarized. The developer's Mac must stay awake with the test service and tunnel running. Original Wii U resource files are not bundled; the built-in renderer is available immediately.
