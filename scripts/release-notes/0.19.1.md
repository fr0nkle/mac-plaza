Fixes a crash when Mac Plaza starts or resumes music, including after another app plays audio or a call ends. Missing optional soundtrack files now use the built-in fallback safely instead of attempting to load a resource bundle from the development Mac.

Custom music, automatic audio muting, crossfades, saved Miis, notes and settings are preserved. Miiverse music remains bundled for offline playback.

Verified with 23 focused audio/resource checks and an installed-style app with no optional recordings.

Mac: Apple silicon, macOS 15 or later. This testing preview is ad-hoc signed.

The Windows preview remains [Plaza for Windows 0.2.0](https://github.com/fr0nkle/mac-plaza/releases/tag/windows-v0.2.0).
