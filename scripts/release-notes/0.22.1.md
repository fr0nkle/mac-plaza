Mac Plaza now uses Developer ID signing and Apple notarization for downloads outside the Mac App Store. The app, installer and disk image include notarization tickets, with Hardened Runtime and secure signing timestamps.

This release retains Public Miiverse, Discord-verified names, Private and Friends Only post audiences, the bug reporter, and all saved Miis, notes, drafts and settings. The app identifier and Sparkle update key remain unchanged.

macOS may still show its normal first-open confirmation for an internet download. The unsigned/unnotarized developer blocks should no longer apply on Macs that allow identified developers.

Mac: Apple silicon, macOS 15 or later.
