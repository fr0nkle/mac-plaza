Mac installation help
  1. Open the downloaded disk image and run Install Mac Plaza.pkg, or drag the app to Applications.
  2. Quit any older copy, then open Mac Plaza from Applications.
  3. Connect Discord in the app. Choose a Mii and enable sharing to let your Discord friends see it.

This testing preview isn’t Apple notarized. If macOS blocks it and you trust the download, try opening it, then choose Open Anyway in System Settings → Privacy & Security.

Mac 0.21.0 adds direct Discord sign-in, saved offline discussions, queued likes and replies, a unified Miiverse, livelier Mii visits and full-screen wandering. Resource packs remain optional local imports from Settings → Mii Appearance.

Your plaza runs locally. Direct Discord sign-in and friends work while the Plaza service is offline. Shared post delivery, bot statuses and in-app updates still use the shared service; saved discussions stay readable and queued changes retry when it reconnects.
