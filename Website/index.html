Come on in

Three little steps.
Then you’re home.

No GitHub account, Python, or Tailscale installation needed.

  1. 01

    Install Mac Plaza

    Open the downloaded disk image. Run Install Mac Plaza.pkg, or drag the app into Applications. Open the copy in Applications.

  2. 02

    Connect Discord

    Open Discord & Friends, click Connect Discord, and approve Discord’s authorization. The connection address is already set up.

  3. 03

    Choose a Mii to share

    Create or select your Mii, enable “Share my chosen Mii and note with my Discord friends,” then save your shared profile. Both friends do this to see each other’s chosen Miis.

Before you download

A preview, made for trying together.

The local plaza works offline. Discord sharing and updates need the test service online; availability can vary while it’s hosted on the developer’s Mac.

If macOS asks for approval

This preview is ad-hoc signed and isn’t Apple notarized. If you trust this copy, try opening it, then use System Settings → Privacy & Security → Open Anyway. Apple’s instructions ↗

Custom statuses and game activity

You and your friend need a shared Discord server containing the Plaza bot for custom statuses and other games. A server administrator adds the bot once from Discord & Friends. Discord’s privacy settings apply. No messages are read.

Automatic updates

Update checks begin after linking Discord. Use Mac Plaza → Check for Updates anytime, or choose your automatic update preferences in Settings.

Source, music, and licenses

Original project code is MIT licensed. Third-party components keep their own licenses, including the AGPL renderer and the separately licensed Discord SDK. The installer includes corresponding source. Nintendo recordings and console resources aren’t included; local imports remain optional.
