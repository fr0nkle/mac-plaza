# Mac Plaza 0.13.3 — friends, games, and a simpler setup

- Adds a Friends menu over the wallpaper, searchable Discord friends, custom Mii assignment, and friend status notes.
- Discovers installed Mac Steam games and adds game shortcuts, artwork, and store descriptions. Friends gather around matching games and apps.
- Adds a categorized Settings overlay with independent music controls and improved wallpaper/audio behavior.
- Improves crowd continuity, loose gatherings, and walking between app islands.
- Adds a download page and permanent latest-installer/source links without requiring GitHub accounts.
- Licenses original project code under MIT and preserves third-party notices. The installer includes corresponding source; standalone Discord SDK files and local Nintendo recordings are omitted from source distributions. Distributable apps use synthesized ambience unless the user imports local music.

Requires Apple silicon and macOS 15+. This testing preview is ad-hoc signed, not Apple notarized. Discord features and downloads need the test hosting Mac online. The repository remains private.
