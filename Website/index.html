The first Windows companion includes an animated plaza, character customization, notes, drawings, likes and replies. Connect Discord, then exchange a Plaza invitation with your Mac or Windows friend. Native wallpaper mode and automatic Discord friend discovery are currently Mac features.

Mac installation help
  1. Open the downloaded disk image and run Install Mac Plaza.pkg, or drag the app to Applications.
  2. Quit any older copy, then open Mac Plaza from Applications.
  3. Connect Discord in the app. Choose a Mii and enable sharing to let your Discord friends see it.

This testing preview isn’t Apple notarized. If macOS blocks it and you trust the download, try opening it, then choose Open Anyway in System Settings → Privacy & Security.

The local plaza works offline. Discord sharing and in-app updates need the test service online.

Windows installation & sharing
  1. Run the downloaded Setup EXE, or extract the entire portable ZIP and open Plaza.exe.
  2. Open Settings → Connect Discord. Approve in your browser, then return to Plaza.
  3. Open Friends → Create invitation and share the code with your friend, or enter their code. Accept the friend request.
  4. On Mac, invitations are under Discord & Friends → Optional shared Mii profiles & Plaza invitations.
  5. Choose Public · Plaza friends when writing a note. Friends on either platform see it on the next refresh. Mac friends need version 0.16 or later.

This Windows preview is unsigned, so SmartScreen may show an unknown-publisher warning. Check that you downloaded it from the linked GitHub release. The app needs no Node, Python or GitHub account.

Private notes and drafts work offline. Sign-in and sharing need the Plaza test service online. Unsent shared notes stay saved on your computer until the service reconnects.
