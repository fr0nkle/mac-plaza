A bottom-right Write Note button opens the composer, beside an Activity button with an unread badge. Both windows float above the moving wallpaper, like Settings and Mii Maker, and close back to the same plaza. Opening an untouched composer preserves saved drafts and creates no empty draft. Activity shows friend likes and replies, opens their notes, and supports marking individual entries or all current entries read. Read state survives restarts and stays separate from the plaza save. Self-interactions and retry duplicates do not notify; withdrawn, blocked and revoked interactions are excluded. Optional macOS banners can be enabled from Activity. Updates arrive while Mac Plaza is running.

Note and reply writing now has a separate offline soundtrack with independent volume/import controls and crossfades back to plaza music. The requested local recording remains local and is excluded from distributable packages.
