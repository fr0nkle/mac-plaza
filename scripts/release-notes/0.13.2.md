# Stable address for friend testing

- Uses https://mac-plaza.tail1400d.ts.net through a dedicated userspace Tailscale Funnel device. The address survives tunnel restarts; testers need no Tailscale installation.
- Includes Start/Stop Friend Test controls for the hosting Mac, preserving its device identity, database, and credentials.
- Fresh installs use the stable address automatically. Existing developer addresses migrate while custom service addresses remain unchanged. Install this DMG once and reconnect Discord when moving from an older endpoint.
- Signed automatic updates continue through the authenticated Plaza service; the GitHub repository remains private.

Requires Apple silicon and macOS 15+. This preview is ad-hoc signed and is not Apple notarized. The hosting Mac must remain powered on, awake, and online.
