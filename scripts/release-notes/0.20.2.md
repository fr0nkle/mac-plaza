Adds **Settings → Mii Appearance → Import Plaza Resource Pack…**. Choose the private `.plazapack` file you received to restore original Mii faces, bodies, animations and menu soundtracks.

The app validates the pack and test-renders Miis before installing. Replaced resources and music selections are backed up; saved Miis, notes, apps, accounts and volume preferences stay in place. Imported music works with the existing preview, replacement, crossfade and automatic mute controls.

The resource pack is supplied separately and is not included in this GitHub release. Existing audio crash fixes are retained. Requires Apple silicon and macOS 15 or later.
