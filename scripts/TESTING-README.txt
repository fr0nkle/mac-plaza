MAC PLAZA 0.21 — TESTING PREVIEW

Requires an Apple silicon Mac and macOS 15 or later.

1. Quit any older copy of Mac Plaza. Open Install Mac Plaza.pkg to install
   in Applications. Alternatively, drag Mac Plaza.app onto Applications.
2. Open Mac Plaza from Applications.
3. Click Connect Discord and approve Discord's account authorization.
4. Choose or create a Mii. Enable Share my chosen Mii and note with my
   Discord friends, then click Save Shared Profile.
5. Your Discord friends using this same service can now see your chosen Mii.
   No Plaza invitation codes are needed.

For custom Discord statuses and other games, you and your friend must share
a Discord server containing the Plaza bot. A server administrator installs
it once from Discord & Friends. No messages are read.

Updates: automatic checks begin after Discord sign-in. Preferences lets you
change automatic download/install. The Mac Plaza menu also has Check for
Updates. Updates preserve local Miis, journals and settings.

Direct Discord sign-in, friends and availability run on your own Mac.
Shared Mii/note delivery, bot status lookup and in-app updates still use
the shared service. Saved discussions remain readable while it is offline;
new likes, replies and profile changes retry when it returns. The connection address remains the same when
the tunnel restarts. Your friend does not need Tailscale installed.
The local plaza continues working offline.

This preview is not Apple notarized. macOS may block the installer/app.
If you trust the copy you received, Apple's Privacy & Security settings
provide an Open Anyway option. Developer ID signing and notarization are
planned for wider distribution. Never disable Gatekeeper globally.

Original Wii U resource files are not included. The built-in character
renderer works without them; imports in Preferences are optional.

Corresponding Source.zip contains the source and component license notices
for this build. Downloads are available at https://plaza.squidproductions.org
even when the developer’s Mac is offline. No GitHub account is required.
